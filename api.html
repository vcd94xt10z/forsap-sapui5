forsap.IntegerInput

Controle baseado em sap.m.Input para entrada de valores inteiros, com validação para números inteiros e suporte a valores negativos.

Visão geral

Controle baseado em sap.m.Input para entrada de valores inteiros, com validação para números inteiros e suporte a valores negativos.

Uso

<forsap:IntegerInput
    id="quantityInput"
    width="100%"
    value="{/quantity}"
    placeholder="Informe a quantidade" />

Comportamento

  • Aceita apenas dígitos.
  • Aceita valores negativos.
  • O sinal - alterna o sinal do valor.
  • O sinal + remove o sinal negativo.
  • Utiliza inputmode="numeric" no elemento HTML interno.
  • Preserva o último valor válido quando uma entrada inválida é identificada.

forsap.DecimalInput

Controle baseado em sap.m.Input para entrada de valores decimais, com configuração da quantidade de casas decimais e formatação com ponto para milhares e vírgula para decimais.

Visão geral

Controle baseado em sap.m.Input para entrada de valores decimais, com configuração da quantidade de casas decimais e formatação com ponto para milhares e vírgula para decimais.

Uso

<forsap:DecimalInput
    id="weightInput"
    width="100%"
    value="{/weight}"
    decimalPlaces="2"
    placeholder="Informe o peso" />

Comportamento

  • Aceita números.
  • Aceita valores negativos.
  • Aceita . e , como entrada decimal.
  • Utiliza inputmode="decimal" no elemento HTML interno.
  • Formata o valor conforme decimalPlaces.
  • Utiliza . como separador de milhares.
  • Utiliza , como separador decimal.
  • Preserva o último valor válido quando uma entrada inválida é identificada.

forsap.VendorInput

Controle baseado em sap.m.Input que fornece um campo de entrada com Value Help para seleção de fornecedores.

Visibilidadepública
Estendesap.m.Input
Móduloforsap/VendorInput
Bibliotecaforsap
Visão geral Propriedades Eventos Métodos

Visão geral

Controle baseado em sap.m.Input que fornece um campo de entrada com Value Help para seleção de fornecedores.

Uso

<forsap:VendorInput
    id="vendorInput"
    width="100%"
    value="{/Supplier}"
    placeholder="Selecione o fornecedor..."
    vendorSelected=".onVendorSelected" />

Comportamento

  • Abre um Value Help com tabela de fornecedores.
  • Disponibiliza pesquisa por ID do fornecedor, nome e documento.
  • Consulta por padrão a entidade A_Supplier.
  • Solicita Supplier, SupplierName e TaxNumber1.
  • Limita a carga inicial a 100 registros.
  • Utiliza filtros Contains nos campos Supplier, SupplierName e TaxNumber1.
  • Após a seleção, o Input recebe o número do fornecedor.
  • O evento vendorSelected entrega o objeto completo através de getParameter("vendor").
  • Para o Value Help, a consulta OData V2 é executada sem $batch e o estado original do modelo é restaurado após a consulta.

Métodos

Value Help

O diálogo apresenta os filtros ID do fornecedor, Nome e Documento, além das colunas Fornecedor, Nome e Documento.

Consulta OData: /sap/opu/odata/sap/API_BUSINESS_PARTNER/A_Supplier

Evento vendorSelected

O evento disponibiliza o fornecedor selecionado no parâmetro vendor.

onVendorSelected: function (oEvent) {
    const oVendor = oEvent.getParameter("vendor");

    console.log(oVendor.Supplier);
    console.log(oVendor.SupplierName);
    console.log(oVendor.TaxNumber1);
}

O objeto recebido contém os campos retornados pela consulta da API, por exemplo:

{
    Supplier: "1000000057",
    SupplierName: "Adidas AG",
    TaxNumber1: "700000057"
}
